Privacy policy

Last updated: 28 October 2026

Home AI is a private assistant running on the owner's own server. Its only user is the owner.

What data is accessed

With the owner's permission, Home AI accesses the owner's Google Calendar (events and calendars) through the Google Calendar API.

How it is used

Calendar data is used only to show the owner their schedule and to create or change events at the owner's request. Every create, update or delete action requires the owner's explicit confirmation.

Storage and sharing

OAuth tokens are stored encrypted on the owner's home server. To answer the owner's requests, relevant calendar entries are passed to the AI language-model provider that powers the assistant; this is done only for the owner's own requests and scheduled summaries. Calendar data is not sold, not shared with anyone else and not used for advertising. Google user data is not used to train or improve AI models.

Home AI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
